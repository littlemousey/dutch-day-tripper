# Dutch Day Tripper

An interactive fiction day-trip game set in Dutch cities, starting with Utrecht.
Pick a city, land with a day's worth of time/money/energy, and spend it on
real locations around town — each with short narrative outcomes and a bit of
randomness.

See `CLAUDE.md` for full context, the current known bug, and a suggested
project structure if you're picking this up with Claude Code.

`prototype/utrecht-day-out.html` is the working single-file starting point —
open it in a browser (ideally via a local dev server, not directly as a file)
to see where things currently stand.
